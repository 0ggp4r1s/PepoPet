# PepoPet 🐾

A cute animated desktop pet built with Python and PySide6.

PepoPet is a small desktop companion that lives on your screen, reacts to interactions and brings a little personality to your desktop.

## ✨ Features

- Animated character with multiple states.
- Pet interaction by clicking.
- Feed interaction by double-clicking.
- Drag the character around your desktop.
- Transparent window background.
- Keyboard shortcuts.
- Context menu with additional actions.

## 🛠️ Requirements

- Windows
- Python 3.10 or newer
- PySide6

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/0ggp4rls/PepoPet.git
cd PepoPet
```

Install dependencies:

```bash
py -m pip install -r requirements.txt
```

## 🚀 Run PepoPet

```bash
py pepo.py
```

## 🎮 Controls

| Action | Control |
|---|---|
| Pet Pepo | Left-click |
| Feed Pepo | Double-click |
| Move Pepo | Click and drag |
| Celebrate | Ctrl + Alt + F9 |
| Close | Ctrl + Alt + Q or Escape |
| Open menu | Right-click |
